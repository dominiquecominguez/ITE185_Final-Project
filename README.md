TaskFlow – Student Task Management System

Where student productivity meets simplicity.
Plan smarter, study better, and stay on top of everything — all in one clean and intuitive task management workspace.

Features

Core Functionality

Create, read, update, and delete (CRUD) tasks

View full task details including title, description, status, and timestamps

Organized task list with clean UI

Multiple status options: Pending, In Progress, On Hold, Cancelled, Completed

User Interface

Modern, student-friendly design

Gradient buttons with hover effects

Clean layout consistent with TaskFlow branding

Responsive and easy to navigate

Authentication

Login and registration system

Session-based user access

Restricted pages without authentication

Database

MySQL database for storing user accounts and tasks

Includes export file: student_todo_db.sql
